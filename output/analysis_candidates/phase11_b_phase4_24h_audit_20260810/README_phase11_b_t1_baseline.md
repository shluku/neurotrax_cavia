# phase11_b_t1_baseline

This additive table starts from the existing phase11_b_t1_baseline cohort and adds all nine recommended proximity/light features.

The supplemental values were extracted using the Phase 4-style T1 24-hour primary/fallback window. They are prefixed with `supplemental_t1_` and remain T1 baseline context. For this cohort, their role is: T1 supplemental features for baseline phenotype exploration.

The original Phase 11/12 files are unchanged. No models are run by this builder.
