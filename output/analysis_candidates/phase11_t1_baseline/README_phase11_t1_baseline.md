# Phase 11 T1 Baseline Midpoint Cohort

This is the Phase 4 baseline analysis applied to the first half of the patient-level interval from T1 to the T1/T2 midpoint. Patients without a valid T2 use the documented 123-day midpoint fallback. All valid mapped devices are pooled. Light, barometer, Bluetooth-proximity, and accelerometer feature work remains outside this active exploratory model cohort and is retained for a later combined analysis.
