# T1 Lexical and Word-Timing Follow-up: Memory, Motor and IQ

This versioned follow-up tests the three T1 outcomes that were outside the original v1 families: Memory, Motor and IQ. It reuses the saved strict T1 aggregates, fixed token thresholds, coverage adjustment and bootstrap procedure. It is exploratory and same-cohort evidence, not independent validation.

The analysis tested 57 feature–outcome pairs across the same three feature families: lexical diversity/repetition, word length, and timing variability. Thresholds remained fixed at 20 reliable tokens for simpler measures, 50 for MATTR-50, and 100 for MATTR-100/MTLD. Coverage adjustment controlled for active days, canonical observations, valid intervals, package count, device count and reliable fraction. A fixed minimum-100-token sensitivity was also retained.

Three nominal p<.05 findings were observed:

- MATTR-100 → Motor T1: ρ=.544, n=21, p=.0108, bootstrap CI [.137, .819], q=.1615; coverage-adjusted ρ=.562, p=.0080, q=.1195.
- Completion MAD → Motor T1: ρ=−.297, n=48, p=.0407, CI [−.550, −.018], q=.576; adjusted ρ=−.275, p=.0590.
- 2–3-character-group completion IQR → IQ T1: ρ=−.287, n=48, p=.0481, CI [−.550, .011], q=.576; adjusted ρ=−.249, p=.0884.

None passes the unadjusted family FDR threshold q<.05. The MATTR-100/Motor signal is based on only 21 patients and requires long, high-quality token sequences; it is especially vulnerable to text quantity, language and application composition. These estimates should not be interpreted as evidence of a validated lexical or motor biomarker.

The full results table includes exact p-values, Spearman effects, bootstrap intervals, q-values, coverage-adjusted estimates and fixed-100-token sensitivities. Historical v1 outputs remain unchanged. No T2 data, raw text, words, vocabularies, hashes or embeddings were used.
