# Cross-Modal Literature Register

This register separates published measures from proposed features for the SensorDB workstream. Published studies below use richer key-event or proprietary sensing streams than our timestamped text-state snapshots, so reproduction is labeled exact, approximate, or inspiration only.

| Study | Population | Modalities and published measures | Synchronization/windowing | Cognitive/outcome evidence | Reproduction status |

## Interpretation for this project

The strongest directly relevant precedent is Ning et al., which explicitly aligned motion with typing sessions. The ABOARD study supports reliability checks but uses a dedicated keystroke keyboard and 14-day windows. The older-adult guide supports aggregate sessions, pauses, deletions and app context, while Butler et al. demonstrates large-scale multimodal collection but not a directly reproducible passive-only cognition result. None of these papers licenses interpreting SensorDB snapshot intervals as true key hold or flight times.

## Phase 2 implementation status — 2026-10-22

The timestamp synchronization pilot was attempted using saved event samples and a bounded SensorDB connection. Saved files were review samples rather than complete episodes, and the database host was unreachable (`Unknown MySQL server host`). Therefore no literature-derived cross-table feature was implemented, no simultaneous overlap was claimed, and no ACC jerk was calculated. The implementation-status copy is `cross_modal_feature_discovery_v2/literature_to_feature_matrix_v2.csv`.
