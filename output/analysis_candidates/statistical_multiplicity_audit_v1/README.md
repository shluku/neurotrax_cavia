## Reproducibility

The audit was generated by `scripts/run_statistical_multiplicity_audit_v1.py` using saved discovery, patient-level window, cognitive, validation, and mechanism-audit outputs. Historical discovery files were not modified. The maxT analysis uses 1,000 common patient-level outcome permutations within outcome across the 204 longitudinal tests and is explicitly labeled as exploratory because it is not nuisance-covariate adjusted or independently prespecified.
