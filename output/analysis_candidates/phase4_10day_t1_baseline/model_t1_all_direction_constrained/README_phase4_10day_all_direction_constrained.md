# Phase 4 10-Day All-Feature Direction-Constrained Ridge

Every feature with sufficient fold-local observed variation receives a direction constraint derived from its fold-local T1 trend. Positive-trend features have nonnegative coefficients and negative-trend features have nonpositive coefficients. This is exploratory and is compared with the same mean baseline.

Pooled mean-baseline RMSE: `8.532`

Pooled all-feature direction-constrained RMSE: `8.899`
