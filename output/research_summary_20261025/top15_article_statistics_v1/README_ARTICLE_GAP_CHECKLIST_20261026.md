# Article gap checklist — Top-15 workstream

This is the current working checklist for preparing the article statistics around the focused top-15 evidence set. It is a planning and documentation artifact; it does not change historical analyses. Statuses are updated as evidence is assembled.

The checklist deliberately separates association statistics from predictive performance and keeps independent validation as future work. Each task must link to a saved table, source code definition, or an explicit missing-statistic note before it is marked complete.
