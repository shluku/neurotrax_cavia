# CI audit for the top-15 forest plot

The forest-plot table was audited against saved patient-level files only. No SensorDB query or new feature extraction was run.

Four CI-missing rows had matching patient-level inputs:

- T1 median word-completion time versus Global, Attention, and Executive Function, using the saved T1 window features and cognitive table.
- T1 morning inter-event-interval IQR versus Executive Function, using the saved T1 window features and cognitive table.

For these rows, 500 patient bootstrap resamples were applied to the same rank-residual partial-Spearman definition used by the discovery code, adjusting for age, sex, and education. The updated intervals are stored in `top15_feature_cognition_associations_20261025.csv` and labeled `recomputed_from_saved_patient_level_inputs`.

The restricted 50/50 midpoint sensitivity rows and the legacy trimmed word-completion rows do not have matching patient-level inputs saved for their exact cohorts and preprocessing. Their CIs remain unavailable; no substitute cohort was used.

The expanded all-association table contains 1,871 historical rows. It retains 990 saved CIs and adds 372 CIs recomputed from exact saved patient-level inputs: the demographic-adjusted Signal Discovery rows and the historical thirds partial-Spearman rows. The remaining 509 rows are explicitly marked as unavailable because their exact paired inputs or preprocessing were not recoverable. The table is a separate view and does not overwrite the Master Association Table.
