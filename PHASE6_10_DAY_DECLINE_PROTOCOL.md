# Phase 6 10-Day T1-to-T2 Decline Digital Phenotyping

This is an isolated equivalent of the original Phase 6 workflow using the Phase 4 10-day T1 baseline estimates and Phase 7 10-day T2 features.

- T1 estimate: independent Phase 4 10-day primary/domain model estimate.
- T2 estimate: independent Ridge model using only Phase 7 10-day T2 feature levels.
- Digital change: `estimated T2 - estimated T1`.
- Observed change: `observed T2 - observed T1`.
- Same global and cognitive-domain model structure, cross-validation, baseline comparisons, and graph order as original Phase 6.

The original Phase 6 24-hour outputs are not overwritten. Results remain exploratory because the cohort is small and T2 feature availability remains limited.
