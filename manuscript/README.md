# Research Manuscript Workspace

This folder is the working source of truth for the first research manuscript.

## Working study frame

**Working title:** From SensorDB to Patient-Level Digital Phenotyping: A Coverage-Aware Proof-of-Concept Study of Baseline Cognition in Dementia

**Study type:** Exploratory observational proof-of-concept and methods/feasibility study.

**Central message:**

> In a small, heterogeneous dementia cohort, we developed and audited a patient-level digital phenotyping pipeline linking passive smartphone data with baseline cognitive performance. The study demonstrates the practical challenges of coverage, missingness, feature-window selection, and model interpretability. Exploratory feature associations were observed, but they did not yet produce a clinically reliable prediction model. These results define the requirements for future, better-powered validation studies.

This is a working research frame, not a claim of clinical validation. The manuscript must distinguish primary analyses, exploratory analyses, and future work.

## Operating rule

Streamlit displays this workspace, but these files remain the editable source of truth. New analyses should be added to the evidence register before being promoted into the main manuscript. Existing project phases remain unchanged.
