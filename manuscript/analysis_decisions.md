# Analysis Decisions Log

This log records decisions that affect the manuscript. It is intentionally separate from the exploratory phase protocols.

## 2026-08-17: Initial manuscript frame

- Position the work as an exploratory observational proof-of-concept and methods/feasibility study.
- Make coverage, missingness, window selection, and interpretability central scientific results.
- Do not present the current model as a clinically validated digital phenotype score.
- Use the mean baseline as the common comparator for model claims.
- Keep all previous project phases intact; select a frozen subset for the main manuscript and report the rest as sensitivity or exploratory analyses.

## Open decisions for supervisor review

- Primary cohort: Phase 11 midpoint-span, Phase 4 24-hour, or another prespecified cohort.
- Primary outcome: global T1 only or global T1 plus selected cognitive domains.
- Role of Phase 12 and Phase 111 longitudinal analyses in the first manuscript.
- Whether proximity, light, and accelerometer features are mature enough for the initial paper.
- Main-paper versus supplement allocation for the many exploratory models.
- Target journal and reporting checklist.

## Interpretation guardrails

- Nominal p-values are not treated as confirmed discoveries after multiplicity correction.
- A model with a small numerical improvement but poor absolute fit remains exploratory.
- Missingness is not automatically a biological signal.
- “First of its kind” should only be used after a formal literature review; otherwise use “to our knowledge” cautiously.
